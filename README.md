# Leitura Betânia

Aplicativo de acompanhamento de leitura do Seminário Evangélico Betânia.

## Instalar no iPhone

1. Abra o site no Safari.
2. Toque em **Compartilhar**.
3. Escolha **Adicionar à Tela de Início**.

Depois da primeira abertura online, o app shell e a logo ficam disponíveis offline. Os livros, aprendizados, perfil e tema são salvos localmente no navegador do aparelho. Use **Perfil → Backup** para exportar ou importar seus dados.

As leituras pessoais têm planejamento próprio e ficam separadas das fichas do compromisso anual do SEB.
